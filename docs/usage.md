# サムネぽん（ThumbPon）の使い方（エージェント向け）

サムネイル画像を作る Web ツール。**ブラウザの中で完結**し（サーバー送信なし）、画像・テキスト・図形を重ねて PNG に書き出す。
このファイルは、ツールの操作と、作業プロジェクト（`.thumbpon` フォルダ）の構造・書き換えの注意をまとめたもの。
プロジェクトの場所（作業フォルダ）は使う側のリポジトリの決まりに従う。
スキル `thumbpon-usage` は、このリポジトリ（react-thumbpon）を手元に clone してある前提で使う。

## 要点（スキル `thumbpon-usage` から最初に読むところ）

- 起動は `npm install`（初回のみ）→ `npm run dev`（http://localhost:5173、Chrome / Edge）
- マニフェストは素の JSON。読むのは自由だが、**直接書き換えるのは最後の手段**
  （ブラウザが同じフォルダに接続中だと保存で上書きされる。書き換えたら「プロジェクトを開く」で読み直す）
- **PNG 書き出しはコマンドだけでできる**（画面は開かない）。`npm run build`（初回・コード変更後）→
  `npm run export -- --project <プロジェクトのフォルダ> --out <出力先> [--thumbnail <名前>]...`。
  詳細は `docs/usage.md` の「コマンドで書き出す」。見た目の最終確認は人がブラウザで行ってもよい
- ツール本体（コード）を直すときは `CLAUDE.md` / `AGENTS.md` → `docs/instructions/agent-guide.md` の順に読む

## 起動

```bash
cd <react-thumbpon のフォルダ>
npm install        # 初回のみ
npm run dev        # http://localhost:5173
```

- 開発サーバーを使わず `npm run build` → `npm run preview` でも動く（静的サイトなので `dist/` だけで足りる）
- **Chrome / Edge で開く**。ローカルフォルダへの保存（File System Access API）は Chromium 系のみ

## プロジェクトを開く・保存する

作業プロジェクトは、使う側のリポジトリが決めたフォルダ（`Thumbpon/` など）。

1. 「プロジェクト」→「プロジェクトを開く」→ **`Thumbpon/` フォルダ**を選ぶ（`.thumbpon` ファイルではなくフォルダ）
2. 以後は `⌘ + S` で同じフォルダへ上書き保存。素材は増減した分だけ書き込まれる
3. リロードで権限が切れたら、画面上部の案内から再接続する

- ブラウザ内の自動保存（IndexedDB）は**復旧用**。バックアップや受け渡しには使わない
- フォルダに接続している間は**フォルダ側が正**。起動時にそちらを読む
- 別のプロジェクトを開くときは「開く」を使う。「保存」で別フォルダを上書きしない
- 受け渡しは「エクスポート」で `.thumbpon.zip`、「インポート」で復元（インポート後はフォルダ接続が外れる）
- **フォントは同梱されない**。別の PC では同じフォントを「フォントファイル追加」で読み直す
  （テロップは標準 Web フォントの `M PLUS 2` なので読み直しは要らない）

## 画面

左サイドバーに 3 パネル、中央にキャンバス。区切り線のドラッグで幅・高さを変えられる。

| パネル     | できること                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| サムネイル | 切替・追加（`＋`）・名前変更（ダブルクリック）・複製・コピー貼り付け・フォルダ分け・キャンバスサイズ変更 |
| レイヤー   | 背景・画像・テキスト・図形の選択、並び替え、詳細編集                                                     |
| 素材       | 画像の登録とフォルダ整理（PNG / JPEG / WebP / SVG）                                                      |

キャンバスはズーム・パン・画面フィット。右上に `PNG書き出し`。

## 基本の流れ

1. **サムネイルを選ぶ／追加**。キャンバスサイズは**サムネイルごと**。YouTube 用は `フルHD 1920×1080` か `HD 1280×720`
   （他に X 1600×900、OGP 1200×630、縦 1080×1920 などのプリセットと `カスタム`）
2. **素材を足す**
   - 画像: キャンバスへドラッグ&ドロップ、または素材パネルのタイルをクリック（中央に配置）／ドラッグ（好きな位置に配置）
   - テキスト: レイヤーパネルの `＋ テキスト`
   - 図形: `＋ 図形`（四角形・円）
3. **配置を整える**: ドラッグで移動、8 つのハンドルでリサイズ、上のハンドルで回転
4. **重なり順を決める**: レイヤー一覧のドラッグ、または右クリック →最前面／最背面
5. **PNG書き出し**: キャンバス実寸で出る。ファイル名はサムネイル名。表示中が 2 枚以上ならダイアログで 1 枚ずつ選ぶ（全選択＝一括）。選択枠などは写らない

## 操作リファレンス

### レイヤー

| 操作             | 方法                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| 移動             | ドラッグ／矢印キー 1px／`Shift` + 矢印 10px                                                           |
| リサイズ・回転   | ハンドル。`Shift` で比率維持・軸固定・回転 15° 刻み                                                   |
| 削除             | `Delete` / `Backspace`                                                                                |
| 表示切替・ロック | 行の `👁` / `🔓`。**ロック中はキャンバスで掴めない**ので一覧から選ぶ                                  |
| スナップ         | キャンバス端・中央・他レイヤーに吸着。`Alt` で一時無効、右下ボタンで ON/OFF。回転中のレイヤーは対象外 |
| 右クリック       | 前後移動・複製・表示・ロック・左右反転・クロップ・削除                                                |

**重なり順は「一覧の下ほど前面」**（配列の末尾が最前面）。

### 画像

- 透明度・左右反転（枠は動かさず中身だけ鏡像）・ブラー／シャドウ／光彩
- **クロップ**: プロパティの `枠で調整`（キャンバス上の枠をドラッグ）、`上/下/左/右を切る` のスライダー、または右クリック。割合で持つのでリサイズしても崩れない

### テキスト

- 内容・フォント・サイズ・太さ・揃え・色・字間・行間・縁取り・エフェクト
- キャンバス上でダブルクリックして直接入力（`Enter` 改行、`Esc` か外クリックで終了）
- 範囲選択して適用先を「選択部分」にすると、色・サイズ・フォント・太さ・斜体・縁取りを**部分的に**変えられる
- 左右ハンドルで折り返し幅、角ハンドルで文字サイズ（部分サイズも比例）
- 高さは持たず内容に応じて伸びる

### 背景

レイヤー一覧の最上部 `BG 背景` から。4 種類。

| 種類           | 設定                                                 |
| -------------- | ---------------------------------------------------- |
| 単色           | 色                                                   |
| グラデーション | 開始色・終了色・角度                                 |
| 画像           | 素材、`cover` / `contain` / タイル、位置、下地色     |
| パターン       | 水玉／ライン／チェック、間隔、色、太さ、角度、下地色 |

### エフェクト（画像・テキスト・背景・図形）

ブラー、シャドウ（ずらし X/Y・ぼかし・色・濃さ）、光彩（広がり・色・濃さ）。
影と光彩は矩形ではなく**文字や透過画像の輪郭に沿う**。

### プリセット

テキストスタイルと背景設定を名前付きで保存し、別のサムネイルで再利用できる。
テキストプリセットを適用すると部分書式は解除される。

## プロジェクトファイルの構造

フォルダに保存すると次の形になる。

```
Thumbpon/
  Thumbpon.thumbpon        マニフェスト（JSON。サムネ・レイヤー・プリセットのすべて）
  assets/
    BG/<素材id>.png         素材パネルのフォルダ名でディレクトリが分かれる
    Character/<素材id>.png
```

- マニフェスト名はフォルダ名から決まる。1 フォルダに複数あるときは短い名前が優先される
- 素材のファイル名は `<素材id>.<拡張子>`。**表示名は JSON の `assets[].meta.name`** にあり、ファイル名からは分からない
- 素材の振り分けは `assetFolders`（`BG` / `Character`）で、ディレクトリ名と一致する

### マニフェスト（`format: "thumbpon-project"`, `version` 7）

| キー                                | 中身                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------- |
| `folders`                           | サムネイルのフォルダ `{id, name, collapsed}`（例: `lec-game`）              |
| `thumbnails`                        | サムネイルの配列。下記                                                      |
| `currentThumbnailId`                | 開いているサムネイル                                                        |
| `assets`                            | `{meta: {id, name, mime, width, height, createdAt, folderId}, file}`        |
| `assetFolders`                      | 素材フォルダ `{id, name, collapsed, parentId?}`（`parentId` で入れ子）      |
| `textPresets` / `backgroundPresets` | プリセット                                                                  |
| `fonts`                             | 使用フォントの参照 `{label, family, source: local\|file}`（実体は含まない） |

`thumbnails[]`:

```
{ id, name, folderId, canvas: {width, height}, background: {...}, layers: [...] }
```

- `layers[0]` が最背面。`zIndex` は無い
- 座標・サイズはキャンバス実寸 px、**レイヤー左上基準**。`rotation` は度、`opacity` は 0..1
- 共通: `id, name, x, y, width, rotation, opacity, visible, locked, effects`

| `type`  | 追加のキー                                                                                                                                                                                       |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `image` | `assetId, height, crop{top,right,bottom,left}, flipX`                                                                                                                                            |
| `text`  | `text`（改行は `\n`）, `inlineStyles?`, `fontFamily`, `fontSize`, `fontWeight`, `fontStyle`, `textAlign`, `letterSpacing`, `lineHeight`, `color`, `strokeWidth`（0 で縁取りなし）, `strokeColor` |
| `shape` | `height, shape(rectangle\|ellipse), cornerRadius, fillType(color\|gradient\|pattern), color, gradientFrom/To/Angle, pattern, patternColor/Size/Weight/Angle`                                     |

`effects`: `blur, shadowEnabled, shadowX, shadowY, shadowBlur, shadowColor, shadowOpacity, glowEnabled, glowBlur, glowColor, glowOpacity`

`background`: `type(color|gradient|image|pattern), color, gradientFrom/To/Angle, assetId, fit(cover|contain|tile), position, tileWidth, pattern..., effects`

欠けたキーは読み込み時に既定値で補われる（古い version のファイルも開ける）。

## Claude Code から扱うとき

- **読む**: マニフェストは素の JSON。構成の確認には `jq` や Python で十分
- **直接書き換えるのは最後の手段**。ブラウザが同じフォルダに接続中だと、ブラウザ側の保存で**上書きされる**。
  編集するならブラウザ側を閉じるか、書き換え後に「プロジェクトを開く」で読み直してから触る
- 書き換えるときの注意
  - `assetId` は `assets[].meta.id` に存在すること。存在しない参照は壊れる
  - 素材を足すなら、ファイルを `assets/<フォルダ名>/<id>.<拡張子>` に置き、`assets[]` に `meta` と `file` を足す（`folderId` は `assetFolders` の id）
  - `id` は UUID。新規レイヤーは新しい UUID を振る
  - テキストの `fontFamily` は引用符つき（`"\"M PLUS 2\", sans-serif"`）。PC フォントなら `fonts[]` の `family` と一致させる
## コマンドで書き出す

画面を開かずに PNG にできる。ヘッドレスの Chrome でアプリを開き、ZIP インポート → 画面の「PNG書き出し」と同じ処理でダウンロードを受け取る。見た目は画面の書き出しと一致する。

```bash
npm run build      # 初回と、アプリのコードを直したあと（dist/ が古いと反映されない）
npm run export -- --project <フォルダ|.thumbpon.zip> --out <出力先> [--thumbnail <名前>]... [--lang ja|en]
```

- `--project`: マニフェスト（`*.thumbpon`）と `assets/` があるフォルダ。バックアップ（`*.thumbpon.before-…`）は読まない
- `--thumbnail`: サムネイル名。省略すると全部。**同名が複数あるときは上から順に `名前.png`、`名前 (2).png`…** になる
  （同じ名前を 2 回指定すると 1 つ目・2 つ目を出す）。無い名前はエラーで、あるものを一覧する
- 人が開いているサムネぽんには触れない（一時プロファイルで動く）。保存済みのマニフェストの内容が出力になる
- ブラウザは入っている Chrome。`THUMBPON_BROWSER_CHANNEL=msedge` で Edge にもできる
- フォントは Google Fonts から取るのでネットワークが要る
- 全 64 枚のような大きいプロジェクトでも、ZIP は一時ファイル経由で渡すので動く
