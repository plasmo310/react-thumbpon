# サムネぽん / ThumbPon — 現行仕様

最終更新: 現在の実装に基づく仕様。将来の検討や実装計画は `docs/plan/` に置き、この文書には含めない。

## 概要

ThumbPon は、ブラウザ内で複数のサムネイルを編集し、PNG またはプロジェクトファイルとして保存できるローカル完結型のサムネイル作成アプリである。  
画像・フォント・プロジェクトデータはユーザーの端末内で扱い、アプリから外部サービスへ送信しない。

## 画面と編集機能

画面はヘッダー、左サイドバー、中央キャンバスで構成する。  
左サイドバーにはサムネイル、レイヤー、素材の各パネルを置き、区切り線をドラッグして幅と高さを変更できる。  
これらのレイアウト値はブラウザに保存する。

### サムネイル

- サムネイルを追加、名前変更、複製、削除、コピー、貼り付けできる。最後の1枚は削除できない。
- サムネイル用フォルダを追加、名前変更、開閉、削除できる。フォルダを削除しても中のサムネイルは未分類として残す。
- サムネイルはフォルダ間を移動できる。
- キャンバスサイズはサムネイルごとに保持し、`1920 × 1080` と `800 × 600` を選択できる。

### キャンバスとレイヤー

- キャンバスはズーム、パン、画面へのフィット表示に対応する。
- 画像素材のドロップ、または OS からの画像ファイルのドロップで、画像レイヤーを追加できる。
- テキスト、画像、図形のレイヤーを追加、選択、移動、リサイズ、回転、複製、削除、表示切替、ロックできる。画像レイヤーはクロップもできる。
- レイヤーの並び順は配列順で管理し、一覧でのドラッグまたは順序操作で変更できる。末尾のレイヤーが最前面となる。
- スナップを有効にすると、移動中のレイヤーを他レイヤーおよびキャンバス中央へ吸着できる。Alt を押している間は一時的に無効化する。
- 選択中のレイヤーは Delete / Backspace で削除できる。矢印キーで 1px、Shift + 矢印キーで 10px 移動する。

### プロパティ

- 画像レイヤーは位置、サイズ、回転、透明度、表示、ロック、クロップ、エフェクトを編集できる。
- テキストレイヤーは文字列、フォント、文字サイズ、太さ、配置、文字色、行間、字間、エフェクトを編集できる。
- 図形レイヤーは四角形または円を選べ、四角形の角丸、単色・グラデーション・パターンの塗り、エフェクトを編集できる。
- 背景は色、画像、グラデーションを設定でき、背景画像には表示方法と位置を設定できる。
- テキストおよび背景のプリセットを保存・適用できる。
- ローカルフォントを読み込み、テキストレイヤーに適用できる。

### 素材

- PNG、JPEG、WebP、SVG などブラウザが画像として扱えるファイルを素材に追加できる。
- 素材をフォルダで整理し、追加、名前変更、開閉、削除、移動できる。フォルダ削除時に中の素材は未分類として残る。
- 素材のメタデータと画像本体は IndexedDB に保存する。素材を削除すると、それを参照する画像レイヤーと背景画像の参照も外す。

## 保存と書き出し

- 編集中のドキュメント、プリセット、スナップ設定はブラウザの IndexedDB に自動保存し、起動時に復元する。
- 現在のキャンバスを、表示倍率に依存しない実寸 PNG として書き出せる。選択枠などの編集 UI は出力に含めない。
- プロジェクトを `.thumbpon.zip` としてエクスポートし、インポートできる。ZIP にはマニフェストと画像素材を含めるが、フォントファイルは含めない。
- Chromium 系ブラウザでは File System Access API を使い、プロジェクトフォルダを開く・保存する操作を提供する。未対応ブラウザではこれらの操作を表示しない。
- Ctrl/Cmd + S は、フォルダ連携に対応するブラウザで接続済みプロジェクトを保存する。

## データとプライバシー

- Zustand の状態には JSON 化できるデータだけを置く。
- Blob は IndexedDB、Object URL はメモリ上のキャッシュで管理し、状態に保存しない。
- ユーザーが扱う画像、フォント、プロジェクトデータは端末内のブラウザストレージまたはユーザーが選んだローカルフォルダに保存する。
