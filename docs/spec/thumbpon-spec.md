# サムネぽん / ThumbPon — 現行仕様

最終更新: 現在の実装に基づく仕様。将来の検討や実装計画は `docs/plan/` に置き、この文書には含めない。

## 概要

ThumbPon は、ブラウザ内で複数のサムネイルを編集し、PNG またはプロジェクトファイルとして保存できるローカル完結型のサムネイル作成アプリである。  
画像・フォント・プロジェクトデータはユーザーの端末内で扱い、アプリから外部サービスへ送信しない。

## 画面と編集機能

### 表示言語

- 日本語と英語に対応する。初期表示は日本語で、ヘッダーの言語選択から即座に切り替えられる。
- 選択言語はブラウザの localStorage に保存し、次回起動時に復元する。保存が利用できない環境でも、そのセッション内の切り替えは可能。
- 起動時に `?lang=en`（英語）または `?lang=ja`（日本語）を指定できる。優先順位は有効なURL指定、保存済み設定、日本語。URL指定の言語も保存し、次回URL指定なしで開く際に引き継ぐ。未対応の値や空の値は無視する。
- URLは起動時にだけ参照する。起動後はヘッダーで言語を切り替えられるが、URLは書き換えない。同じURLを再読み込みした場合は、再びURL指定を優先する。
- メニュー、プロパティ、ツールチップ、操作結果、確認ダイアログを翻訳する。新規項目の初期名と初期テキストは作成時の言語を使う。
- 言語変更で既存の名前・テキスト・プリセット・フォント名を変更しない。言語設定はプロジェクトファイルと Undo/Redo の対象に含めない。

画面はヘッダー、左サイドバー、中央キャンバスで構成する。  
左サイドバーにはサムネイル、レイヤー、素材の各パネルを置き、区切り線をドラッグして幅と高さを変更できる。  
これらのレイアウト値はブラウザに保存する。

### サムネイル

- サムネイルを追加、名前変更、複製、削除、コピー、貼り付けできる。最後の1枚は削除できない。
- サムネイル用フォルダを追加、名前変更、開閉、削除できる。フォルダを削除しても中のサムネイルは未分類として残す。
- サムネイルはフォルダ間を移動できる。
- 一覧のチェックでサムネイルをCanvasに常時表示できる。編集中の1枚もチェックの有無によらず表示する。フォルダのチェックは操作時点の配下を一括選択・解除し、一部選択は中間状態で示す。フォルダを閉じても常時表示は維持する。
- キャンバスサイズはサムネイルごとに保持し、フルHD、HD、4:3、Reels / Shorts / TikTok、X 投稿、Instagram 投稿・正方形、OGP / Facebook の各プリセット、または任意のカスタムサイズを選択できる。

### キャンバスとレイヤー

- キャンバスはズーム、パン、画面へのフィット表示に対応する。マウスホイールとトラックパッドのピンチでズーム、トラックパッドの2本指スクロール・中ボタンドラッグ・Space を押しながらの左ドラッグでパンする。
- 複数表示時はCanvas右上で列数指定・行数指定を切り替え、1以上の整数を入力する。初期値は2列で、反対の方向は表示枚数から自動計算する。表示枚数より大きい指定は保持するが、空の行・列は増やさない。
- 表示順は未分類、フォルダ順、フォルダ内のサムネイル順。サイズが異なるサムネイルも縦横比を保って同じ大きさのセルに収め、左上から行方向に並べる。
- Canvas上のサムネイルを操作すると編集対象が切り替わり、最初のドラッグからレイヤーを編集できる。編集対象は常に1枚で、選択枠・ガイド・レイヤーパネル・ショートカットはその1枚を対象にする。
- 複数表示中のズーム・パン・フィットはグリッド全体へ適用する。配置・表示対象・キャンバスサイズの変更時はフィットし直す。素材や画像はドロップしたサムネイルへ追加する。
- 画像素材のドロップ、または OS からの画像ファイルのドロップで、画像レイヤーを追加できる。
- テキスト、画像、図形のレイヤーを追加、選択、移動、リサイズ、回転、複製、削除、表示切替、ロックできる。画像レイヤーはクロップもできる。
- レイヤーの並び順は配列順で管理し、一覧でのドラッグまたは順序操作で変更できる。末尾のレイヤーが最前面となる。
- スナップを有効にすると、移動中のレイヤーを他レイヤーおよびキャンバス中央へ吸着できる。Alt を押している間は一時的に無効化する。
- 選択中のレイヤーは Delete / Backspace で削除できる。矢印キーで 1px、Shift + 矢印キーで 10px 移動する。

### プロパティ

- 画像レイヤーは位置、サイズ、回転、透明度、表示、ロック、クロップ、エフェクトを編集できる。
- 画像レイヤーにはオーバーレイマスクを重ねられる。オン／オフ、色、不透明度（0〜100%）を指定でき、初期設定はオフ・黒・50%。マスクはクロップ後の画像枠全体を覆い、画像の移動・リサイズ・回転・反転に追従する。マスク設定は保存・複製・PNG書き出しに含まれ、旧データはマスクなしで読み込む。
- 画像プロパティの「画像」欄から取り込み済みの素材を選び、画像だけを差し替えられる。レイヤー名・配置・サイズ・クロップ・反転・エフェクトなどの設定を保持し、同じ素材を使う他のレイヤーや背景には影響しない。縦横比の異なる素材でもサイズを保持するため、必要に応じてクロップ欄で比率を調整する。
- テキストレイヤーは文字列、フォント、文字サイズ、太さ、配置、文字色、行間、字間、エフェクトを編集できる。
- テキストはキャンバス上でダブルクリックすると直接入力できる。Enterで改行、Escapeまたは編集領域外のクリックで編集を終了する。
- テキストの縁取りは内側・外側の2つを指定でき、それぞれ色と幅を全体または選択部分に適用できる。縁2の幅は縁1の外周から広げるオフセット(px)で、0で無効になる。縁2は縁1を含む文字の形をそのまま背面で広げて描き、文字の配置や縁1のストローク幅を変えない。両方の設定はテキストプリセット、保存データ、PNG書き出しに含まれる。
- 文字を範囲選択し、適用先を「選択部分」にすると色、サイズ、フォント、太さ、斜体、縁取りを部分変更できる。サイズの異なる文字は基準線で下揃えになる。
- 配置、行間、字間、透明度、エフェクトはテキスト全体で共通。全体のサイズ変更と角のリサイズは部分サイズも比例変更し、角のリサイズでは背景の余白と角丸も比例変更する。
- キャンバス上の行間は、折り返しを含む行と行の間だけに適用する。一行の場合や、最初の行の上・最後の行の下には行間による余白を付けず、背景の外側の余白はパディングで調整する。
- 行の高さは「自動／固定」を選べる。自動は従来の行間倍率を使い、固定はpxで指定し、明示改行・折り返しに共通の行送りを適用する。固定時は最初と最後の行の上下も行高に含め、部分的な大きな文字で行送りを広げない。設定は保存・複製・テキストプリセット・PNG書き出しに含み、旧データは自動で復元する。角のリサイズでは固定の行高も比例変更する。
- 新規テキストは自動フィットがオン。明示的な改行ごとに一行とし、最長行と背景の左右余白に幅を合わせ、高さは内容と上下余白に追従する。自動フィットはボタンでオン・オフを切り替えられ、幅入力や左右リサイズではオフにして折り返す。旧データは保存済みの幅を維持する。
- テキスト背景は単色の矩形で、背景の有無、色、上・右・下・左それぞれの余白（px）、角丸（px）を指定できる。角丸は「全体指定／個別指定」で切り替え、個別指定では四隅を設定する。モード切替だけでは各モードの設定値を保持し、全体の角丸を変更すると四隅にも同じ値を反映する。初期値は背景なし、白、余白と角丸は0、角丸は全体指定。旧データの角丸は四隅にも引き継ぐ。余白は上／下・左／右、個別角丸は左上／右上・左下／右下の2列×2行で表示する。背景設定はテキストプリセットに含み、自動フィット設定は含まない。
- テキストプリセットは全体書式を保存し、適用すると部分書式を解除する。
- 図形レイヤーは四角形または円を選べ、四角形の角丸、単色・グラデーション・パターンの塗り、エフェクトを編集できる。
- 背景は色、画像、グラデーションを設定でき、背景画像には表示方法と位置を設定できる。
- テキストおよび背景のプリセットを保存・適用できる。
- ローカルフォントを読み込み、テキストレイヤーに適用できる。
- Noto Sans JP、M PLUS 1p、M PLUS 2、Roboto は標準選択肢として Google Fonts から読み込み、PC へのインストールなしで利用できる。太さは 400 / 700 / 900、Roboto は斜体も取得する。他の3書体の斜体はブラウザが合成し、収録されていない文字や通信失敗時は代替フォントで表示する。

### 素材

- PNG、JPEG、WebP、SVG などブラウザが画像として扱えるファイルを素材に追加できる。
- 素材をフォルダで整理し、追加、名前変更、開閉、削除、移動できる。フォルダ削除時に中の素材は未分類として残る。
- 素材フォルダには子フォルダを作成できる。フォルダ名をドラッグして他フォルダ内へ移動でき、行の上下端では並べ替えできる。子フォルダは「最上位へ移動」で階層から外せる。親の開閉は子フォルダにも適用し、削除時は子フォルダも削除してすべての素材を未分類に残す。保存・プロジェクト書き出しでも階層を保持する。
- 素材のメタデータと画像本体は IndexedDB に保存する。素材を削除すると、それを参照する画像レイヤーと背景画像の参照も外す。

## 保存と書き出し

- 編集中のドキュメント、プリセット、スナップ設定はブラウザの IndexedDB に自動保存し、起動時に復元する。
- 常時表示のチェックとグリッド設定もブラウザ内で復元するが、プロジェクトファイル・フォルダ保存・Undo履歴には含めない。表示設定のみの変更は未保存扱いにしない。別プロジェクトの読み込み・新規作成ではチェックを解除し、グリッド設定は保持する。
- Canvas に表示中のサムネイルを、表示倍率に依存しない実寸 PNG として書き出せる。複数表示中は表示中の全枚を表示順に1枚ずつ保存し、ボタンに枚数を表示する。同名のファイル名には「 (2)」などの連番を付ける。すべて描画できた場合だけ保存する。選択枠などの編集 UI は出力に含めない。
- プロジェクトを `.thumbpon.zip` としてエクスポートし、インポートできる。ZIP にはマニフェストと画像素材を含めるが、フォントファイルは含めない。
- Chromium 系ブラウザでは File System Access API を使い、プロジェクトフォルダを開く・保存する操作を提供する。未対応ブラウザではこれらの操作を表示しない。
- Ctrl/Cmd + S は、フォルダ連携に対応するブラウザで接続済みプロジェクトを保存する。

## データとプライバシー

- Zustand の状態には JSON 化できるデータだけを置く。
- Blob は IndexedDB、Object URL はメモリ上のキャッシュで管理し、状態に保存しない。
- ユーザーが扱う画像、フォント、プロジェクトデータは端末内のブラウザストレージまたはユーザーが選んだローカルフォルダに保存する。
- 標準 Web フォントの CSS とフォント本体は `fonts.googleapis.com` / `fonts.gstatic.com` から取得する。初回取得にはネット接続が必要で、編集内容やローカルフォントをこの通信に含めない。
- 標準 Web フォントの著作権表示と SIL Open Font License 1.1 全文を `public/licenses/fonts/` に置き、公開ビルドへ同梱する。詳細は [Web フォントとライセンス](web-fonts.md) を参照する。
