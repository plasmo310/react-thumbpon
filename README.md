# サムネぽん / ThumbPon

テンプレートをベースに画像とテキストを差し替えて、**サムネイル画像を効率よく制作する**ためのWebツールです。

Illustrator / Photoshop / Figma を毎回開かずに、決まったレイアウトの画像をさっと作ることを目的にしています。自由度よりも、速さ・軽さ・操作の少なさを優先しています。

画像は**サーバーに送信されません**。読み込み・編集・保存・書き出しはすべてブラウザ内で完結します。

要件定義: [docs/plan/thumbpon-spec.md](docs/plan/thumbpon-spec.md) ／ 実装計画: [docs/plan/thumbpon-phase1-plan.md](docs/plan/thumbpon-phase1-plan.md)

---

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェックのみ
npm run test       # テスト（tests/）
npm run build      # 型チェック + 本番ビルド（dist/）
npm run format     # Prettier で整形
npm run preview    # ビルド結果の確認
```

Node.js 20 以降を想定しています。

## 使い方

### サムネイル

1枚の制作物が「サムネイル」です。複数持てて、フォルダで分類できます。

| 操作 | 方法 |
| --- | --- |
| 切り替え | 行をクリック |
| 名前変更 | 行をダブルクリック |
| 追加 | パネル右上の `＋`（フォルダ行の `＋` でそのフォルダ内に追加） |
| 複製 | 行にホバー → `⧉` |
| コピー / 貼り付け | 行の `📋` でコピー → パネル右上かフォルダ行の `📥` で貼り付け |
| フォルダへ移動 | 行をフォルダへドラッグ |
| 削除 | 行の `🗑`（削除後はひとつ上のサムネイルへ移動） |

**キャンバスサイズはサムネイルごと**に持ちます。一覧で選択中の行の下に `サイズ` が開くので、そこで変えます。プリセット（1920×1080 / 800×600）のほか「カスタム」で任意のサイズを指定できます。

### 画像を置く

- OSから画像ファイルを**キャンバスに直接ドラッグ&ドロップ** → 落とした位置に配置されます
- 素材パネルに追加しておいて、そこからキャンバスへドラッグ、またはクリックで中央に配置
- 対応形式: PNG / JPEG / WebP / SVG

素材はブラウザの IndexedDB に保存されるので、リロードしても消えません。

**素材はフォルダで分類できます。** パネル右上の `📁` でフォルダを追加し、タイルをドラッグして入れます。

| 操作 | 方法 |
| --- | --- |
| フォルダを追加 | パネル右上の `📁` |
| 名前変更 | フォルダ名をダブルクリック |
| そのフォルダに追加 | フォルダ行の `＋`、またはフォルダへ画像ファイルをドロップ |
| フォルダへ移動 | 素材タイルをフォルダへドラッグ |
| 削除 | フォルダ行の `🗑`（中の素材は消えず未分類へ戻ります） |

このフォルダ分けは**プロジェクトを書き出したときの `assets/` の中身にもそのまま出ます**
（`assets/<フォルダ名>/<id>.png`）。未分類の素材は `assets/` の直下に置かれます。

### クロップ

画像レイヤーは**表示する範囲を切り詰められます**。切り落とす量は割合で持つので、
レイヤーを拡大縮小してもクロップは崩れません。

- プロパティ欄の `枠で調整` を押すと、キャンバスの枠が青くなりクロップ編集になります。
  そのまま8つのハンドルを内側へドラッグすると、**中身は動かさずに枠だけが詰まります**
  （切り落とされる部分は薄く表示されます）
- `上/下/左/右を切る` のスライダーでも詰められます
- `比率` は、切ったあとの見た目が伸びないように枠の高さを合わせます
- `解除` で画像全体に戻ります

レイヤーを右クリック（一覧でもキャンバス上でも）→「クロップを調整」でも同じ編集に入れます。

### 左右反転

画像レイヤーはプロパティ欄の `反転` → `左右` で鏡像にできます（右クリックメニューの `左右反転` でも同じ）。
**枠は動かさず中身だけが反転**し、影や光彩の向きはそのままです。クロップしていれば、切り取った見た目がそのまま反転します。

### レイヤー

**一覧の下にあるものが前面**です（一番上が背景）。

- ドラッグ&ドロップで並び替え（挿入位置に線が出ます）
- 選択すると行の下にプロパティが開きます
- 行の 👁 で表示/非表示、`🔓` でロック
- 選択中は `↑` 背面へ / `↓` 前面へ / `⧉` 複製 / `🗑` 削除
- **右クリック**すると、`最前面へ移動` / `前面へ移動` / `背面へ移動` / `最背面へ移動` と
  複製・表示切り替え・ロック・左右反転・クロップ・削除をまとめたメニューが出ます。
  **一覧の行でも、キャンバス上のレイヤーでも同じメニュー**で、右クリックした対象が選択されます
  （ロック中のレイヤーはキャンバスでは掴めないので、一覧から操作してください）

キャンバス上では、ドラッグで移動、8つのハンドルでリサイズ、上のハンドルで回転できます。

| キー | 動作 |
| --- | --- |
| `Delete` / `Backspace` | 選択レイヤーを削除 |
| 矢印キー | 1px 移動 |
| `Shift` + 矢印キー | 10px 移動 |
| `Shift` + ドラッグ | 縦横どちらかに固定 |
| `Shift` + リサイズ | 縦横比を維持（画像） |
| `Shift` + 回転 | 15度単位 |
| `Alt` + ドラッグ | スナップを一時的に無効化 |

### スナップ

移動中に、レイヤーの端・中央が次の線に吸着します。

- キャンバスの端と中央
- 他のレイヤーの端と中央

吸着した位置にマゼンタのガイド線が出ます。キャンバス右下のボタンで ON/OFF、`Alt` を押している間は一時的に無効になります。回転しているレイヤーは対象外です。

### テキスト

`＋ テキスト` で追加し、プロパティで内容・フォント・サイズ・太さ・揃え・字間・行間・色・**縁取り**を設定します。

- サイド（左右）ハンドル: 折り返し幅を変える
- コーナーハンドル: 文字サイズを比例して拡大縮小

### フォント

内蔵フォントに加えて、2通りの方法で増やせます（テキストのプロパティ内のボタン）。

- **PCのフォントを読み込む** — OSにインストール済みのフォント一覧を取得します（Chrome系のみ。権限ダイアログが出ます）
- **フォントファイル追加** — `.ttf` / `.otf` / `.woff` / `.woff2` を読み込みます。IndexedDB に保存され、次回起動時に自動で復元されます

> **注意:** フォントファイルはプロジェクトに含まれません（同梱すると**フォントの再配布**にあたるため）。記録されるのは使用フォントの**名前だけ**なので、別のPC・別のブラウザで開くと代替フォントで表示されます。その際は画面上部に「フォント『◯◯』が見つかりません」と名前付きで表示されるので、同じフォントを読み込み直せば元の見た目に戻ります。

### 背景

レイヤー一覧の一番上の `BG 背景` を選ぶと設定できます。種類は4つです。

| 種類 | 設定できること |
| --- | --- |
| 単色 | 色 |
| グラデーション | 開始色・終了色・角度 |
| 画像 | 素材・敷き方（cover / contain / タイル）・表示位置またはタイル幅・下地色 |
| パターン | 模様（水玉 / ライン / チェック）・間隔・模様の色・太さ・角度・下地色 |

素材を敷き詰めたいときは、パターンではなく `画像` の敷き方で `タイル` を選びます（タイルは模様の種類ではなく、1枚の画像の敷き方だからです）。パターンは画像を作らず CSS のグラデーションで描いているので、書き出しても劣化しません。

### エフェクト

テキスト・画像・**背景**のどれにも、プロパティの一番下から同じように掛けられます。

| 効果 | 内容 |
| --- | --- |
| ブラー | レイヤー全体をぼかす |
| シャドウ | 同じ形の影を指定した量だけずらして落とす（ずらしX / Y・ぼかし・色・濃さ） |
| 光彩 | 輪郭のまわりを光らせる（広がり・色・濃さ） |

影も光彩も矩形ではなく**中身の形**（文字の輪郭・画像の透過・模様の隙間）に沿います。

背景では**下地色を除いた絵柄**（画像・グラデーション・パターン）に掛かります。`contain` の画像やパターンのように隙間のある背景では、影や光彩がその形に沿って出ます。単色は絵柄を持たず何も変わらないため、エフェクト欄自体を出していません（設定した値は種類を戻せば残っています）。

### プリセット

テキストのスタイルと背景設定は、名前を付けて保存し再利用できます。プロパティの「プリセット」行から `＋` で保存、選択で適用、`🗑` で削除します。プリセットは自動保存され、プロジェクトファイルにも含まれます。

### 保存と書き出し

保存先は2通りあります。**ローカルフォルダ**を作業場所にするか、**1つのファイル**として受け渡すかです。

| 用途 | 操作 |
| --- | --- |
| 完成画像 | `PNG書き出し` — 表示倍率に関係なくキャンバス実寸のPNGを出力 |
| 保存する | `プロジェクトを保存`（`Ctrl` / `⌘` + `S`）。未接続なら保存先のフォルダを聞かれる |
| 開く | `プロジェクトを開く` — プロジェクトのフォルダを選ぶ |
| ファイルとして書き出す | `エクスポート` — `.thumbpon.zip` を1つダウンロード |
| ファイルから読み込む | `インポート` — `.thumbpon.zip` を選ぶ |

PNG のファイル名は**サムネイル名**になります。同名のファイルが既にある場合は、ブラウザの仕様で `名前 (1).png` のように連番が付きます。

#### ローカルフォルダをワークスペースにする

`プロジェクトを保存` を押すと保存先のフォルダを聞かれ、そのフォルダが以降の作業場所になります。

```
選んだフォルダ/
  夜景シリーズ.thumbpon   サムネイル・レイヤー・プリセット・素材フォルダ（中身は JSON）
  assets/                 素材画像を元のファイルのまま（未分類）
    背景素材/             素材パネルのフォルダと同じ名前で分かれる
```

- `.thumbpon` の名前は**フォルダ名から作られます**。エクスプローラーで好きな名前に変えても構いません。
  次の保存はその名前に書き戻すので、ファイルが2つ並ぶことはありません

- 一度接続すれば、次からの `保存` はダイアログ無しでそのフォルダに反映されます
- 素材は増減した分だけ書き込むので、保存のたびに画像を書き直すことはありません
- 素材フォルダの名前を変えると、次の保存でファイルも新しい名前のフォルダへ移り、空になったフォルダは残りません
- **素材ファイルは必ず `<id>.<拡張子>` で置かれます。** フォルダの名前を OS 側で変えても、
  読み込み時に id でファイルを拾い直すので素材は失われません
- **読み込みで確かめられなかった素材は消しません。** フォルダ側にファイルが無くても
  ブラウザ内（IndexedDB）に実体が残っていればそれを使い、逆にブラウザ内から実体が
  失われていてもフォルダ側のファイルは消さずに残します。
  どちらにも無かったものだけ、画面上部の通知帯に名前を出します
- リロードしても同じフォルダに繋ぎ直します。ブラウザが権限を忘れていた場合は画面上部に再接続のボタンが出ます
- フォルダ名の左に `●` が出ているときは、まだフォルダに書いていない変更があります
- 保存先に**別のプロジェクトが入っているフォルダ**を選んだときは確認が出ます。`保存` は
  そのフォルダを読み込みません（押した拍子に今の作業が消えないようにするため）。
  読み込みたいときは `プロジェクトを開く` を使ってください

#### プロジェクトを開く

`プロジェクトを開く` では、`.thumbpon` ファイルではなく**それが入っているフォルダ**を選びます。
素材は隣の `assets/` に別ファイルで置かれているので、フォルダごと許可をもらう必要があるためです
（ファイルを選ぶ方式にすると、Web の仕組み上ファイルから親フォルダを辿れず、
続けてフォルダの許可を求める2つ目のダイアログが必要になってしまいます）。

サムネぽんのプロジェクトが入っていないフォルダは開けません。新しい作業場所は
`プロジェクトを保存` から作ってください。

#### ファイルとして受け渡す

`エクスポート` は `.thumbpon.zip` ファイルを1つ書き出します。**中身は上のフォルダ構成をそのまま ZIP に固めただけ**です。画像を再圧縮しないので、容量は素材の合計とほぼ同じになります。他の人に渡すときや、区切りでバックアップを取るときに使ってください。

拡張子が `.zip` で終わっているので、普通の ZIP として解凍・閲覧できます。つまり:

- `.thumbpon.zip` を解凍したフォルダは、そのまま `プロジェクトを開く` で開けます
- ワークスペースフォルダを ZIP にしたものは、そのまま `インポート` で読めます（フォルダごと圧縮して中が一段深くなっていても読めます）

`インポート` で読み込むと、ワークスペースフォルダとの接続は切れます。そのまま保存すると
前のフォルダを別プロジェクトの内容で上書きしてしまうためです。

#### 自動保存について

編集内容はブラウザ内（IndexedDB）に**自動保存**されるので、フォルダに保存する前にリロードしても作業は残ります。ただしこれは復旧用の控えです。**フォルダに接続している間は、フォルダの内容が正**として扱われ、起動時にフォルダの内容で上書きされます。

## 対応ブラウザ

| 機能 | Chrome / Edge | Firefox / Safari / モバイル |
| --- | --- | --- |
| 編集・PNG書き出し | ○ | ○ |
| インポート / エクスポート | ○ | ○ |
| ローカルフォルダ連携（開く / 保存） | ○ | ✕（ボタン自体を出しません） |
| PCのフォント一覧 | ○ | ✕ |

フォルダ連携は File System Access API を使っているため Chromium 系のみです。非対応の環境では `.thumbpon.zip` のインポート / エクスポートで同じことができます。
また、この API は **HTTPS（または localhost）** でのみ動きます。

| 用途 | 採用 |
| --- | --- |
| フレームワーク | React 19 + TypeScript + Vite |

### ディレクトリ

**1機能＝1ディレクトリ**（Feature-based Architecture + Colocation）。
依存は `domain → shared → app/store → features → app` の一方向のみで、
**features 同士は import しません**。

```
src/
  styles.css       色・余白・文字サイズのトークンとリセット
  app/             アプリの組み立て。main / App / layout / config / store（Zustand）
  domain/          UIに依存しない型と純粋な計算。entity ごとに分かれる
                   layer / background / effects / crop / thumbnail / project / geometry ...
  features/        画面に出る機能。中は components / hooks / lib の3分類まで
    thumbnail/     サムネイル一覧・フォルダ・キャンバスサイズ
    layer/         レイヤー一覧 + レイヤー/背景のプロパティ + フォント読み込み
    canvas/        編集キャンバス
    asset/         素材パネル・素材フォルダ
    project/       プロジェクトの開く/保存・フォルダ連携・インポート/エクスポート・PNG書き出し
  shared/
    ui/            汎用UI部品
    lib/           DOM操作の小物（storage/ に IndexedDB と File System Access）
tests/             Vitest。純粋関数・ストア・入出力と、層の境界を検証する
```

この境界は `tests/architecture.test.ts` が検証しているので、
層の逆流や feature 同士の import は `npm run test` で落ちます。

コーディング規約は [docs/instructions/code_guide.md](docs/instructions/code_guide.md) にあります。


### 設計メモ

- **キャンバス内部は常に実寸座標**で扱い、表示だけ CSS `transform: scale()` で縮小します。ポインタ移動量を `/ scale` するだけで座標が合い、書き出しも `transform: none` を渡すだけで実寸になります
- **レイヤーの重なり順は配列順**（index 0 が最背面）。`zIndex` は持ちません
- **テキストレイヤーは高さを持たず** 内容に応じて伸びます。高さが必要な場面（選択枠・スナップ）では DOM から実測します
- **クロップは各辺から切り落とす割合**（0..1）で持ちます。CSS だけで描くので書き出しでも劣化せず、枠を詰めるのと同時にクロップを動かすことで「中身が動かないトリミング」になります
- 状態はすべて JSON 化できる値に保ち、objectURL や Blob はストアに入れません

## まだ無いもの

Undo / Redo、整列コマンド、レイヤーのグループ化、テキストのグラデーション、テンプレート機能、複数画像の一括生成。
