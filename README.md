# サムネぽん / ThumbPon

テンプレートをベースに画像とテキストを差し替えて、**サムネイル画像を高速に量産する**ためのWebツールです。

Illustrator / Photoshop / Figma を毎回開かずに、決まったレイアウトの画像をさっと作ることを目的にしています。自由度よりも、速さ・軽さ・操作の少なさを優先しています。

画像は**サーバーに送信されません**。読み込み・編集・保存・書き出しはすべてブラウザ内で完結します。

要件定義: [docs/plan/thumbpon-spec.md](docs/plan/thumbpon-spec.md) ／ 実装計画: [docs/plan/thumbpon-phase1-plan.md](docs/plan/thumbpon-phase1-plan.md)

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェックのみ
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
```

Node.js 20 以降を想定しています。

## 使い方

### サムネイル

1枚の制作物が「サムネイル」です。複数持てて、フォルダで分類できます。

| 操作 | 方法 |
| --- | --- |
| 切り替え | 行をクリック |
| 名前変更 | 行をダブルクリック |
| 追加 | パネル右上の `＋`（フォルダ行の `＋` でそのフォルダ内に追加） |
| 複製 | 行にホバー → `⧉` |
| コピー / 貼り付け | 行の `📋` でコピー → パネル右上かフォルダ行の `📥` で貼り付け |
| フォルダへ移動 | 行をフォルダへドラッグ |
| 削除 | 行の `🗑`（削除後はひとつ上のサムネイルへ移動） |

**キャンバスサイズはサムネイルごと**に持ちます。ヘッダーのサイズ選択は現在のサムネイルにだけ効きます。プリセット（1920×1080 / 800×600）のほか「カスタム」で任意のサイズを指定できます。

### 画像を置く

- OSから画像ファイルを**キャンバスに直接ドラッグ&ドロップ** → 落とした位置に配置されます
- 素材パネルに追加しておいて、そこからキャンバスへドラッグ、またはクリックで中央に配置
- 対応形式: PNG / JPEG / WebP / SVG

素材はブラウザの IndexedDB に保存されるので、リロードしても消えません。

### レイヤー

**一覧の下にあるものが前面**です（一番上が背景）。

- ドラッグ&ドロップで並び替え（挿入位置に線が出ます）
- 選択すると行の下にプロパティが開きます
- 行の `◉` で表示/非表示、`🔓` でロック
- 選択中は `↑` 背面へ / `↓` 前面へ / `⧉` 複製 / `🗑` 削除

キャンバス上では、ドラッグで移動、8つのハンドルでリサイズ、上のハンドルで回転できます。

| キー | 動作 |
| --- | --- |
| `Delete` / `Backspace` | 選択レイヤーを削除 |
| 矢印キー | 1px 移動 |
| `Shift` + 矢印キー | 10px 移動 |
| `Shift` + ドラッグ | 縦横どちらかに固定 |
| `Shift` + リサイズ | 縦横比を維持（画像） |
| `Shift` + 回転 | 15度単位 |
| `Alt` + ドラッグ | スナップを一時的に無効化 |

### スナップ

移動中に、レイヤーの端・中央が次の線に吸着します。

- キャンバスの端と中央
- 他のレイヤーの端と中央

吸着した位置にマゼンタのガイド線が出ます。キャンバス右下のボタンで ON/OFF、`Alt` を押している間は一時的に無効になります。回転しているレイヤーは対象外です。

### テキスト

`＋ テキスト` で追加し、プロパティで内容・フォント・サイズ・太さ・揃え・字間・行間・色・**縁取り**を設定します。

- サイド（左右）ハンドル: 折り返し幅を変える
- コーナーハンドル: 文字サイズを比例して拡大縮小

### フォント

内蔵フォントに加えて、2通りの方法で増やせます（テキストのプロパティ内のボタン）。

- **PCのフォントを読み込む** — OSにインストール済みのフォント一覧を取得します（Chrome系のみ。権限ダイアログが出ます）
- **フォントファイル追加** — `.ttf` / `.otf` / `.woff` / `.woff2` を読み込みます。IndexedDB に保存され、次回起動時に自動で復元されます

> **注意:** フォントファイルはプロジェクトファイルに含まれません。プロジェクトには使用フォント名だけが記録されるため、**別のPC・別のブラウザで開くと代替フォントで表示されます**。その環境で同じフォントを読み込み直せば元に戻ります。

### 背景

レイヤー一覧の一番上の `BG 背景` を選ぶと設定できます。単色 / グラデーション / 画像（cover・contain・表示位置）に対応しています。

### プリセット

テキストのスタイルと背景設定は、名前を付けて保存し再利用できます。プロパティの「プリセット」行から `＋` で保存、選択で適用、`🗑` で削除します。プリセットは自動保存され、プロジェクトファイルにも含まれます。

### 保存と書き出し

| 用途 | 操作 |
| --- | --- |
| 完成画像 | `PNG書き出し` — 表示倍率に関係なくキャンバス実寸のPNGを出力 |
| プロジェクト保存 | 形式を選んで `保存` |
| プロジェクト読込 | `読込`（ZIP / JSON どちらでも自動判別） |

保存形式は2種類あります。

- **ZIP**（既定・推奨） — `project.json` と `assets/` に画像を**元のファイルのまま**格納します。画像を再圧縮しないので容量は素材の合計とほぼ同じです
- **JSON** — 1ファイルにまとまりますが、画像を base64 で埋め込むため **ZIP の約1.33倍**の容量になります

編集内容はブラウザ内（IndexedDB）に**自動保存**されるので、リロードしても作業は残ります。ただしブラウザのデータを消すと失われるため、区切りごとにプロジェクトを保存しておくことを推奨します。

## 技術構成

| 用途 | 採用 |
| --- | --- |
| フレームワーク | React 19 + TypeScript + Vite |
| スタイル | Tailwind CSS v4（`@tailwindcss/vite`、設定ファイルなし・`@theme` でトークン定義） |
| 状態管理 | Zustand |
| 永続化 | IndexedDB（`idb-keyval`） |
| PNG書き出し | `html-to-image` |
| ZIP | `fflate` |

ドラッグ・リサイズ・回転・スナップはライブラリを使わず Pointer Events で実装しています。

### ディレクトリ

```
src/
  types/editor.ts            Layer / Thumbnail / Background / Preset などの型
  store/editorStore.ts       Zustand ストア（アプリ状態と操作はすべてここ）
  lib/
    db.ts                    IndexedDB のストア定義（1 objectStore + キー接頭辞）
    assetStore.ts            素材画像の保存と objectURL キャッシュ
    fontStore.ts             ローカルフォントの取得・登録・保存
    geometry.ts              回転対応リサイズ / 角度計算
    snap.ts                  スナップ位置とガイド線の算出
    pointerDrag.ts           pointer capture を使ったドラッグセッション
    exportImage.ts           PNG 書き出し
    projectFile.ts           プロジェクトの ZIP / JSON 保存・読込
    workspace.ts             起動時の復元と自動保存
    useKeyboardShortcuts.ts  キーボード操作
  components/
    Header / ThumbnailPanel / LayerPanel / AssetPanel / PropertiesPanel
    canvas/CanvasStage       グレー領域。表示倍率の算出とファイルドロップ
    canvas/CanvasSurface     実寸のキャンバス。背景・レイヤー・ガイドを描画
    canvas/LayerView         レイヤー1枚の描画とドラッグ
    canvas/SelectionOverlay  選択枠・リサイズ/回転ハンドル
    ui/Field.tsx             入力部品
```

### 設計メモ

- **キャンバス内部は常に実寸座標**で扱い、表示だけ CSS `transform: scale()` で縮小します。ポインタ移動量を `/ scale` するだけで座標が合い、書き出しも `transform: none` を渡すだけで実寸になります
- **レイヤーの重なり順は配列順**（index 0 が最背面）。`zIndex` は持ちません
- **テキストレイヤーは高さを持たず** 内容に応じて伸びます。高さが必要な場面（選択枠・スナップ）では DOM から実測します
- 状態はすべて JSON 化できる値に保ち、objectURL や Blob はストアに入れません
